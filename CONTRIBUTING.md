# Contributing

Contributions are welcome! The goal of this repository is to gather useful, relevant links that deserve to be discovered.

## Criteria

- Prioritize useful and less obvious resources.
- Include only public and accessible links.
- Avoid generic websites, social networks, and widely known services.
- Use the most appropriate category for each resource.
- Avoid duplicate entries.

## Organization

Each category has two files:

- `en.md`: content in English.
- `pt-BR.md`: content in Brazilian Portuguese.

Content should only be added to the file corresponding to its original language. Language-independent resources may appear in both versions.

The `github` and `youtube` categories are exceptions to the thematic organization: their own directories bring together projects, tools, channels, videos, and playlists from these platforms, regardless of topic.

## Format

Use the following format:

```markdown
- [Resource Name](https://example.com/)
  A brief and objective description of its usefulness.
```

## How to contribute

1. Fork the repository.
2. Create a branch for your contribution.
3. Add the resource to the corresponding file.
4. Open a Pull Request with a brief description of the change.
