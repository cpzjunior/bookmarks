# Bookmarks

A curated collection of useful links, tools, references, and interesting content available on the internet.

The goal is to gather resources that deserve to be discovered, used, and preserved, prioritizing quality, usefulness, and less obvious content.

## Categories

| Category | Description |
|---|---|
| [`games`](games/) | Games, tools, and resources related to the gaming world. |
| [`github`](github/) | Repositories, open source projects, libraries, and tools available on GitHub. |
| [`youtube`](youtube/) | Channels, videos, and playlists featuring relevant content. |

### Category Organization

Categories are organized by subject whenever possible. However, GitHub and YouTube have their own directories because they are platforms that host resources from different fields.

This separation keeps projects, tools, channels, and content centralized, making them easier to discover without mixing them with thematic categories.

New categories may be added as the collection grows and new subjects warrant their own organization.

## Curation Criteria

- **Usefulness:** resources that offer relevant knowledge, functionality, or references.
- **Discovery:** prioritize less obvious content that deserves to be known.
- **Quality:** favor reliable sources, well-established projects, and well-crafted content.
- **Organization:** each resource should be placed in the most appropriate category, avoiding unnecessary duplication.
- **Context:** each link should include a short description explaining its usefulness.

The goal is not to create a generic directory of websites or gather popular services, but to build a collection of references that are genuinely worth saving and sharing.

## Languages

The content is organized into two versions:

- `en.md`: content in English.
- `pt-BR.md`: content in Brazilian Portuguese.

Content originally published in a given language should appear only in the corresponding file. Language-independent resources may appear in both versions.

## Contribution

Suggestions for new bookmarks are welcome, provided they follow the project's curation and organization criteria.

When adding a resource, include its name, direct link, and an objective description of its usefulness.
