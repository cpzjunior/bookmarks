# GitHub

## AI Agents, Automation and Orchestration

- [500 AI Agents Projects](https://github.com/ashishpatel26/500-AI-Agents-Projectsm): Collection of AI agent use cases and open-source projects across different industries, such as healthcare, finance, education, and retail.
- [Agent Orchestrator](https://github.com/OrchestratorInc/agent-orchestratorm): Platform for planning, executing, and supervising multiple coding agents, with support for Claude Code, Codex, and other tools, as well as desktop and mobile applications.
- [AgentCore Samples](https://github.com/awslabs/agentcore-samplesm): Examples of production-ready AI agent implementations using Amazon Bedrock AgentCore, covering scalability, security, identity, memory, and integration.
- [All Agentic Architectures](https://github.com/FareedKhan-dev/all-agentic-architecturesm): Library and reference material covering agentic AI architectures, including patterns such as Reflexion, LATS, GraphRAG, MemGPT, and Voyager, as well as benchmarks.
- [amosblomqvist/learnharness](https://github.com/amosblomqvist/learnharnessm): Agent-based runtime environment designed to support learning complex subjects.
- [anomalyco/opencode](https://github.com/anomalyco/opencodem): Open-source coding agent designed to assist with software development.
- [anthropics/skills](https://github.com/anthropics/skillsm): Public collection of skills for AI agents, with reusable instructions and workflows to expand their capabilities.
- [anysearch-ai/anysearch-skill](https://github.com/anysearch-ai/anysearch-skillm): Real-time search skill for agents, featuring web search, specialized queries, parallel execution, and content extraction.
- [AutoGPT](https://github.com/Significant-Gravitas/AutoGPTm): Open-source platform for creating and using autonomous artificial intelligence agents, focused on making AI accessible for different applications.
- [chaseai-yt/claudex-loop](https://github.com/chaseai-yt/claudex-loopm): Claude Code skill that structures task planning into stages involving investigation, questioning, adversarial review, and cross-model implementation.
- [Claude Code Game Studios](https://github.com/Donchitos/Claude-Code-Game-Studiosm): Framework that transforms Claude Code into a game development studio, with specialized agents, skills, and task coordination.
- [Composio](https://github.com/ComposioHQ/composiom): Infrastructure for AI agents with integration to over a thousand tools, context management, authentication, and an isolated execution environment.
- [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harnessm): DeepSeek's extensible agent execution framework, based on a plugin-oriented architecture.
- [Dify](https://github.com/langgenius/difym): Collaborative platform for building agentic workflows, RAG pipelines, and applications using AI models and tools, available in the cloud, VPC, or self-hosted.
- [different-ai/openwork](https://github.com/different-ai/openworkm): Open-source alternative to Claude Cowork, based on OpenCode, for delegating tasks to AI agents.
- [Emdash](https://github.com/generalaction/emdashm): Open-source agentic development environment that allows multiple coding agents to run in parallel and use different model providers.
- [experientiallabs/experiential](https://github.com/experientiallabs/experientialm): AI model gateway that allows the use of your own providers or hosted models, with support for local deployment, a marketplace, and cost optimization.
- [Expo Skills](https://github.com/expo/skillsm): Collection of skills for AI agents to work with Expo projects and Expo Application Services (EAS).
- [fabro-sh/fabro](https://github.com/fabro-sh/fabrom): Agent-driven software engineering platform focused on automating development workflows.
- [google/skills](https://github.com/google/skillsm): Skills for AI agents focused on products, services, and technologies within the Google ecosystem.
- [gstack](https://github.com/garrytan/gstackm): Set of tools and workflows for Claude Code that transforms the coding agent into a team of specialists, with roles such as CEO, Designer, Software Engineer, Engineering Manager, Release Manager, and QA.
- [Graph Engineering](https://github.com/codejunkie99/graph-engineeringm): Material and workflows for building knowledge graphs and task graphs used by AI agents.
- [Hermes Agent](https://github.com/NousResearch/hermes-agentm): AI agent from Nous Research, designed to evolve through usage and support different tasks using models and tools.
- [LobeHub](https://github.com/lobehub/lobehubm): AI super-agent platform that allows specialized assistants to be integrated into team conversation and collaboration environments.
- [n8n](https://github.com/n8n-io/n8nm): Workflow automation platform with native AI capabilities, integrations with hundreds of services, and options for cloud-based or self-hosted execution.
- [n8n Skills](https://github.com/czlonkowski/n8n-skillsm): Set of skills for Claude Code to develop and configure automation workflows on the n8n platform.
- [OpenClaw](https://github.com/openclaw/openclawm): AI assistant capable of executing tasks across different operating systems and platforms, with a focus on autonomy and control over its own data.
- [OpenMAIC](https://github.com/THU-MAIC/OpenMAICm): Interactive classroom environment with multiple AI agents, developed to provide collaborative learning experiences.
- [OpenRig](https://github.com/mvschwarz/openrigm): Tool for assembling persistent teams of coding agents, with defined roles, shared context, and division of responsibilities.
- [Orca](https://github.com/stablyai/orcam): Environment for running and orchestrating multiple coding agents using your own subscriptions, with support for desktop, mobile devices, and remote execution.
- [Paperclip](https://github.com/paperclipai/paperclipm): Open-source application for managing and coordinating AI agents in workplace environments.
- [rudderlabs/devbox](https://github.com/rudderlabs/devboxm): Isolated cloud environment for autonomous execution of engineering tasks, with an independent sandbox for each activity.
- [Sample AI Agent Architectures AgentCore](https://github.com/aws-samples/sample-ai-agent-architectures-agentcorem): Step-by-step examples demonstrating the evolution of AI agent architectures, from simple implementations to production-ready solutions using AWS services.
- [Scientific Agent Skills](https://github.com/K-Dense-AI/scientific-agent-skillsm): Scientific skills library for AI agents, with validated resources and integration with databases in biology, chemistry, medicine, drug discovery, and other disciplines.
- [trycompai/crm](https://github.com/trycompai/crmm): Open-source CRM designed for interaction and operation by artificial intelligence agents.
- [UseAgent](https://github.com/useagenthq/useagentm): Open-source alternative to Devin for running Claude Code, Codex, and OpenCode in isolated, self-managed workspaces.
- [vectorize-io/hindsight](https://github.com/vectorize-io/hindsightm): Memory system for AI agents that continuously learns from interactions and stored information.
