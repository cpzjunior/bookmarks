# GitHub

## Agentes de IA e Orquestração

* [AutoGPT](https://github.com/Significant-Gravitas/AutoGPT): Plataforma open source para criação e utilização de agentes autônomos de inteligência artificial, com foco em tornar a IA acessível para diferentes aplicações.
* [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness): Estrutura extensível de execução de agentes da DeepSeek, baseada em uma arquitetura orientada a plugins.
* [Hermes Agent](https://github.com/NousResearch/hermes-agent): Agente de IA da Nous Research, projetado para evoluir com o uso e apoiar diferentes tarefas por meio de modelos e ferramentas.
* [OpenClaw](https://github.com/openclaw/openclaw): Assistente de IA capaz de executar tarefas em diferentes sistemas operacionais e plataformas, com foco em autonomia e controle dos próprios dados.
* [Paperclip](https://github.com/paperclipai/paperclip): Aplicação open source para gerenciamento e coordenação de agentes de IA em ambientes de trabalho.
* [Emdash](https://github.com/generalaction/emdash): Ambiente de desenvolvimento agentic open source que permite executar múltiplos agentes de programação em paralelo e utilizar diferentes provedores de modelos.
* [UseAgent](https://github.com/useagenthq/useagent): Alternativa open source ao Devin para executar Claude Code, Codex e OpenCode em ambientes de trabalho isolados e autogerenciados.
* [AnythingLLM](https://github.com/Mintplex-Labs/anything-llm): Plataforma local-first para criação de experiências com agentes de IA, RAG e modelos multimodais, com possibilidade de hospedagem própria.
* [Dify](https://github.com/langgenius/dify): Plataforma colaborativa para construção de workflows agentic, pipelines RAG e aplicações com modelos e ferramentas de IA, disponível em nuvem, VPC ou instalação própria.
* [Composio](https://github.com/ComposioHQ/composio): Infraestrutura para agentes de IA com integração a mais de mil ferramentas, gerenciamento de contexto, autenticação e ambiente isolado de execução.
* [n8n](https://github.com/n8n-io/n8n): Plataforma de automação de workflows com recursos nativos de IA, integrações com centenas de serviços e opções de execução em nuvem ou infraestrutura própria.

## Modelos, APIs e Infraestrutura de Inferência

* [Awesome Free LLM APIs](https://github.com/open-free-llm-api/awesome-freellm-apis): Catálogo de APIs gratuitas para modelos de linguagem, reunindo provedores como Google Gemini, NVIDIA NIM, Groq e OpenRouter, além de orientações de configuração para ferramentas de desenvolvimento.
* [OmniRoute](https://github.com/cheaper-inference/OmniRoute): Gateway de IA open source que unifica provedores e modelos em um único endpoint, com roteamento, fallback baseado em cotas e recursos para reduzir o consumo de tokens.
* [ClawRouter](https://github.com/BlockRunAI/ClawRouter): Roteador de modelos de linguagem voltado a agentes autônomos, com seleção local de modelos e suporte a pagamentos via USDC nas redes Base e Solana.
* [Ollama](https://github.com/ollama/ollama): Ferramenta para executar localmente modelos de linguagem, incluindo famílias como Kimi, DeepSeek, Qwen, Gemma e outros.
* [llama.cpp](https://github.com/ggml-org/llama.cpp): Implementação em C/C++ para inferência de modelos de linguagem, com foco em execução eficiente em diferentes tipos de hardware.
* [LocalAI](https://github.com/mudler/LocalAI): Engine open source compatível com APIs de IA para executar modelos de linguagem, visão, áudio, imagem e vídeo em hardware próprio, inclusive sem GPU.
* [Open WebUI](https://github.com/open-webui/open-webui): Interface web para interação com modelos de IA, com suporte a Ollama, APIs compatíveis com OpenAI, RAG e instalação própria.
* [Soup](https://github.com/MakazhanAlpamys/Soup): Ferramenta para fine-tuning de modelos de linguagem a partir de uma configuração YAML, com técnicas voltadas a treinar modelos em hardware de consumo.
* [Langfuse](https://github.com/langfuse/langfuse): Plataforma open source de engenharia de IA para gateway, observabilidade de agentes, avaliações e gerenciamento de prompts, com suporte a OpenTelemetry e hospedagem própria.

## Protocolos, Ferramentas e Integrações

* [Awesome MCP Servers](https://github.com/punkpeye/awesome-mcp-servers): Coleção de servidores MCP (Model Context Protocol) para conectar modelos e agentes de IA a ferramentas, serviços e fontes de dados.
* [Firecrawl](https://github.com/firecrawl/firecrawl): Plataforma de crawling e extração de dados da web, projetada para fornecer conteúdo estruturado a agentes de IA e aplicações baseadas em modelos de linguagem.
* [OpenMotion](https://github.com/nexu-io/openmotion): Estúdio open source para criação e edição de vídeos com apoio de IA, incluindo reconstrução de vídeos, edição baseada em HTML e integração com ferramentas e modelos externos.
* [Repowise](https://github.com/repowise-dev/repowise): Ferramenta de inteligência de codebase para pessoas e agentes, com análise de qualidade, documentação, métricas Git, detecção de código não utilizado e decisões arquiteturais via MCP.
* [REA](https://github.com/morluto/rea): Ferramenta para engenharia reversa com agentes, permitindo investigar o comportamento de aplicações e analisar componentes até o nível de binários nativos.
* [Archify](https://github.com/tt-a1i/archify): Skill para transformar ideias, planos ou bases de código em diagramas interativos, apoiando a documentação de arquitetura e o desenho de sistemas.
